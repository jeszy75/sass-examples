sass-examples
=============

This repository contains examples demonstrating the features of the [Sass](https://sass-lang.com/) CSS preprocessor.

Building the examples requires [Dart Sass](https://sass-lang.com/dart-sass/). The easiest way to install Dart Sass is using `npm`:

```bash
npm install -g sass
```

On Linux and macOS systems, you can install `npm` using the [Node Version Manager](https://github.com/nvm-sh/nvm). On Windows, you can use [NVM for Windows](https://github.com/coreybutler/nvm-windows).

To build the examples, run `make` in the `sass` folder. This requires [GNU Make](https://www.gnu.org/software/make/).
